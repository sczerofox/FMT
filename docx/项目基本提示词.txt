7. 命令行命令基础：
(service) service start，
        service stop，
        service uninstall,
        service install;

(file)  1 file upload (本机文件路径)，
        2 file upload （网络路径），
        file download 文件名.png（就会创建网络链接，如：127.0.0.1:4122:\file\download\文件名.png,复制放入浏览器里回车就可以下载）,
        file preview 文件名.png（就会创建网络链接，如：127.0.0.1:4122:\file\preview\文件名.png,复制放入浏览器里回车就可以在浏览器上浏览，(只先实现图片就行，其他的后面在加功能)），
        file list （命令行查看所有文件名：如1234567890.png下一行小谷姐姐麻辣烫.jpg下一行...最后输出统计数据: 共 6789 个文件 (其功能后面再加)），
        file show 文件名.jpg （输出他的信息，如：文件占用大小 ( 67MB )，文件入库时间，最后一次被使用时间，下载次数，分享次数），
        1 file delete 文件名.jpg（软删除，移动到垃圾桶）,
        2 file delete 文件名1.jpg,文件名2.jpg,文件名3.jpg,文件名4.jpg（软删除，移动到垃圾桶）;

(share) share list (查看所有的分享文件(目前可以预览和下载的)格式（输出：127.0.0.1:4122:\share\preview\文件名.png, 文件大小：6MB,失效时间：2026/09/30 08：00：00, 可下载次数：12次）)，
        share show 文件名.png（输出：127.0.0.1:4122:\share\preview\文件名.png, 127.0.0.1:4122:\share\download\文件名.png, 文件大小：6MB,失效时间：2026/09/30 08：00：00, 可下载次数：12次 （如果该文件已经被分享就读取share.json的数据， 显示被分享的文件信息））;

(trash) trash list （查看所有被删除的信息：输出格式：1234567890.png下一行小谷姐姐麻辣烫.jpg下一行...最后输出统计数据: 共 6789 个文件，
        trash show 文件名.jpg （查看这个文件的删除信息,格式：文件大小：7MB, 删除时间：2026/09/30 00：00：00，删除位置：repository\lazyfox\pet-store-system\文件名.jpg（repository(库)\lazyfox(用户名)(不做用户先用 user 代替)\pet-store-system(项目\桶)（先用bucket）\文件名.jpg））,
        trash all 删除trash 文件夹，删除之前提醒用户，用户输入y就执行，其他就不执行任何操作，
        trash 文件名.txt 删除这一个的文件，
        trash rollback 文件名.txt 回滚还原到原目录里。
